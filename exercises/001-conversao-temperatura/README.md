# 🌡️ Exercício 01: Conversor de Temperatura (Celsius para Fahrenheit)

## Enunciado
Escreva um programa que leia uma temperatura em graus **Celsius** (°C) e a converta para **Fahrenheit** (°F).

**Fórmula de conversão:**
$$F = (C \times 9/5) + 32$$

* **Entrada de exemplo:** `25.0`
* **Saída esperada:** `77.0 °F`
